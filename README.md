## 一、注册与防封控核心问题

### 1、为什么总是跳自动化脚本风险提示？
首先，我们需要了解什么是自动化脚本；自动化脚本就是利用自动化程序进行非人为批量注册的行为（这个是平台防止薅羊毛的一种机制）；我们正常使用应该是一IP一账号，但是我们在一个IP下不停的注册账号，所以就会被标记为疑似使用自动化脚本在进行批量注册；所以，只要我们解决这个问题，就能稳定使用了。

### 2、如何有效避免被封控？
① 梯子必须使用个人独享的，不要再用之前搭配的那种共用的梯子了（1000G流量一个月仅需5.9元）
② 用量不大的用户，一个浏览器一天就注册一个账号，需要注册另一个账号的时候就换一个浏览器，切换浏览器的同时切换新节点（这样使用的账号，每天都能刷新积分，基本能用大半个月，所以也能省下很多购买邮箱的费用哦）
③ 用量大的用户，请使用带隔离的浏览器（推荐使用毕方浏览器和火狐浏览器，多个浏览器交叉使用，同一个节点只注册3个账号，间隔10分钟以上）
④ 所有的浏览器只要出现过自动化风险提示就必须删掉历史记录，清理全部浏览器缓存的数据（出现自动化风险提醒后，就先切换节点，换个浏览器使用，不要清完缓存就立马用同一个浏览器注册）

## 二、节点与梯子使用技巧

### 5、清理了缓存、切换了节点还是被封控的解决方法？
① **等**：刚清理完缓存的浏览器，不能立马就注册使用新账号，切换节点后可以先使用其他的浏览器。
② **切换冷门国家**：使用共享的梯子节点时，封控你的时候，也封控了其他人，同一节点上的人都被同时封控了，所以用独享梯子的很少遇到这种情况。
③ **重装**：清理过缓存的浏览器，如果还是出现封控，可以卸载后重装，这样就能正常使用了。

## 三、浏览器与积分疑难杂症

### 3、注册只有30积分的解决方法？
有些用户注册后只有30积分，这个问题是由于网络封控的问题，需要使用比特浏览器进行破解；
① 将梯子的代理模式修改成规则。
② 每次打开比特浏览器窗口的时候，先关闭梯子的系统代理或者关闭梯子，等浏览器窗口打开后，重新开启系统代理或打开梯子。
③ 用比特浏览器打开lovart网址后进行注册，就可以获得70积分。
